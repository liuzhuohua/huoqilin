投资课堂

火麒麟把经典价值投资评分公式翻译成中文, 让每个投资者都能复算

什么是火麒麟评分?

火麒麟评分是一套 100 分制的财务健康评分, 基于 Benjamin Graham + Warren Buffett 经典价值投资公式. 分数越高代表公司财务越健康. 满分 100 分, 投资界普遍认为 50 分以上的公司才算"财务健康".

评分由 8 个维度组成, 每项按权重累加:

ROIC (投入资本回报率)30 分
销售增长 (Sales Growth)16 分
权益增长 (Equity Growth)16 分
EPS 增长 (每股盈利)16 分
自由现金流增长8 分
总资产增长8 分
净利润增长3 分
总负债下降3 分

什么是 MOS (安全边际)?

MOS = Margin of Safety, 是巴菲特最重视的概念. 计算公式: MOS = 100% - (股价 / 合理价)

MOS 越高代表股票越被低估. 火麒麟推荐 50% 以上为买入区.

合理价计算: 火麒麟采用 Benjamin Graham 简化公式 合理价 = EPS × (8.5 + 2 × 增长率)

红绿灯信号

低估买入 评分 ≥ 50 且 MOS ≥ 50% — 财务健康且价格低估, 买入区

观望 评分 ≥ 50 或 MOS ≥ 50% — 只有一项达标, 持续关注

高估卖出 评分 < 50 且 MOS < 50% — 财务不健康且价格高估, 卖出区

算法出处

本系统基于以下经典价值投资公式实现, 全部为公开理论:

  • Benjamin Graham 合理价公式: Fair Value = EPS × (8.5 + 2 × 增长率)
  • MOS 安全边际 (Margin of Safety): 100% - (股价 / 合理价)
  • 100 分制健康评分: ROIC / 销售增长 / 权益增长 / EPS 增长 / FCF 增长 / 资产增长 / 净利增长 / 负债下降 八个维度
  • 红绿灯判定: Score ≥ 50 且 MOS ≥ 50% → 低估买入区
